# Linear Models

This project covers linear models for machine learning: linear regression,
regression evaluation metrics, Ridge and Lasso regularization, SHAP-based
model explainability, logistic regression, decision boundaries, and Support
Vector Machines (SVMs).

## Task 0: Linear Regression

`Linear_Regression()` takes no arguments and returns an untrained
`sklearn.linear_model.LinearRegression` instance, which fits a linear
model to data using ordinary least squares.
